What it does

More than a yes or no.

  • Explains each answer

    Every prediction comes with the factors that pushed it toward late or on time, read straight from the model's weights.

  • Knows the routes

    Distance, typical air time, airlines and past delay rates for {{ ref.stats.routes }} routes fill in automatically.

  • Works before takeoff

    No actual times yet? Enter the schedule alone and the missing values are estimated, with a note saying so.

  • Honest numbers

    Every score on this page was measured on {{ "{:,}".format(m.test_size) }} flights the model never saw during training.

  • JSON API

    The same model is one POST request away, ready for scripts, notebooks or other apps.

  • Light and dark

    Follows the system theme, works on phones, and still runs with JavaScript turned off.

From raw data to prediction

  1. Data 336,776 flights from the nycflights13 dataset, 19 columns each.
  2. Cleaning Missing times and delays filled with column averages.
  3. Encoding Airlines and airports one-hot encoded, timestamps split into parts: 142 inputs in total.
  4. Model Logistic regression from scikit-learn, trained on 80% of the flights.
  5. Target A flight counts as late when it lands even one minute after schedule.

Good to know

  • The model reads actual departure and arrival times, so it is most reliable once the plane is in the air. Before takeoff it leans on estimates.
  • It learned from 2013 traffic. Airlines, schedules and airports have changed since then.
  • Weather is not an input, although it drives many real delays.

Use it from code

Send the same fields as JSON. Times accept "14:05" or 1405, and optional fields can be left out.

Request
curl -X POST {{ request.host_url }}api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "carrier": "UA",
    "origin": "EWR",
    "dest": "ORD",
    "date": "2013-12-20",
    "sched_dep_time": "18:00",
    "sched_arr_time": "19:35",
    "dep_time": "19:10"
  }'
Response
{
  "delayed": true,
  "probability": 0.9998,
  "confidence": "high",
  "verdict": "Likely to arrive late",
  "factors": [
    { "label": "Departure delay", "impact": 7.725 },
    ...
  ],
  "route": { "origin": "EWR", "dest": "ORD", ... },
  "assumptions": ["Distance taken from the route: 719 miles.", ...]
}

Invalid fields come back with status 422 and an errors object. The list of airlines, airports and routes is at GET /api/routes.
